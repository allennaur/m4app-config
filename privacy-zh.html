毛選日曆 隱私政策

隱私版本：v1.1 | 更新日期：2026年7月2日

本隱私政策（以下簡稱「本政策」）闡述了 李安（以下簡稱「我們」）作為 毛選日曆 行動應用程式（以下簡稱「本應用」）的開發者，如何處理本應用在您行動裝置中執行及請求服務時所涉數據的資訊安全規則。

1. 核心理念與離線執行

本應用以保障用戶隱私為根本出發點。本應用之所有核心功能，包括每日金句展示、干支與農曆換算、偏好主題渲染以及您的個人想法記錄，均在您的行動裝置本機安全運算與儲存。

  • 無用戶帳戶：本應用無需註冊或建立任何網路帳戶即可使用，因此絕不收集您的姓名、電話號碼、電子郵件等個人身分識別資料。
  • 本機私有化想法：您的日常想法及歷史記錄完全依託裝置本機的私有沙盒儲存進行保存，不存在任何向雲端同步或上傳的行為。

2. 定位權限與即時天氣服務（平台細分）

當您開啟應用內的「即時天氣」功能或使用桌面小工具時，本應用會向您請求地理位置（定位）權限。我們在不同平台及組件中的處理邏輯如下：

  • Android 裝置：本應用 Android 版本暫不提供天氣服務，因此在 Android 裝置上，本應用不請求任何位置權限，亦不收集或處理任何地理定位數據。
  • iOS 裝置與桌面小工具（Widget）：
    • 主應用程式與小工具通信：當您在 iOS 系統中啟用本應用時，經緯度資訊會以高度安全的本機 App Group 共享機制（Suite: group.xyz.tinglo.Mao4App）在裝置本機的 UserDefaults 中同步，以便桌面小工具（MaoWidget）能即時讀取。該數據完全留存在裝置本機。
    • 小工具背景重新整理：iOS 桌面小工具會在系統排程的背景重新整理期間，讀取此本機經緯度，並直接在小工具進程中向 Open-Meteo API 發起加密 HTTPS 網絡請求以更新桌面小工具的溫度和空氣品質。

    • 🚨 特別說明與承諾：「即時天氣」及「桌面小工具（Widget）背景天氣同步」功能僅在 iOS 裝置上提供與支持，Android 裝置暫不提供天氣服務。我們絕對不在任何外部雲端伺服器上收集、記錄、儲存或回傳您的位置軌跡、歷史定位資訊。您的經緯度數據絕不與您的任何裝置識別碼（如 IDFA/IMEI）或個人身分進行綁定。

3. 其他裝置權限的使用

為了給您提供高品質的使用體驗，本應用還可能會在必要時請求並使用以下硬體權限或通知通道：

  • 通知權限（Local Notifications）：用於實現每日上午的「早安推送」提醒。該通知的觸發、渲染與管理完全在您裝置本機由系統原生通知引擎排程執行，整個流程完全不需要網絡連接，亦不向外發送任何數據。
  • 觸覺回饋權限（Haptics）：用於在您長按、點擊或切換主題卡片時提供震動回饋，以實現極佳的原生互動手感。該權限僅限在硬體層互動，不涉及任何數據的讀取和存留。

4. 第三方 SDK 與數據安全

本應用沒有整合任何第三方商業廣告 SDK、用戶追蹤分析系統（例如 Google Analytics、Firebase、Flurry）或者社交平台一鍵分享組件。沒有任何第三方機構能夠以自動化方式透過本應用獲取或收集您的任何偏好或個人數據。

5. OTA 自動更新檢測

本應用內置了輕量級的 OTA 版本檢測機制。當檢測更新時，應用會訪問雲端的靜態配置檔案（經過 AES 對稱加密的 JSON 包）。整個過程僅對比用戶端的版本號，不收集、不追蹤您的裝置硬體特徵。若裝置處於離線狀態，則自動忽略更新，不干擾您的日常使用。

6. 兒童隱私保護說明

我們非常重視對未成年人隱私的保護。由於本應用不建立用戶帳戶系統，我們亦不主動向任何人收集任何個人數據。如果家長有合理理由懷疑我們在無意中獲得了未成年人的隱私數據，請透過以下方式聯絡我們，我們將立即協助您核實並清除本機配置。

7. 政策修訂

在添加新功能或遵循相關法律政策時，我們可能會不時對本隱私政策進行小幅更新。任何修訂一經本頁面公布即時生效，建議您定期關注。對於原生系統權限的重大變更，我們會在應用內顯著提示並徵求您的明確同意。
