毛选日历 隐私政策

本隐私政策（以下简称“本政策”）阐述了 李安（以下简称“我们”）作为 毛选日历 移动应用程序（以下简称“本应用”）的开发者，如何处理本应用在您移动设备中运行及请求服务时所涉数据的信息安全规则。

1. 核心理念与离线运行

本应用以保障用户隐私为根本出发点。本应用的所有核心功能，包括每日金句展示、干支与农历换算、偏好主题渲染以及您的个人想法记录，均在您的移动设备本地安全运算和存储。

  • 无用户账户：本应用无需注册或创建任何网络账户即可使用，因此绝不收集您的姓名、电话号码、电子邮件等个人身份数据。
  • 本地私有化想法：您的日常想法及历史记录完全依托设备本地的私有沙盒存储进行保存，不存在任何向云端同步或上传的行为。

2. 定位权限与实时天气服务（平台细分）

当您开启应用内的“实时天气”功能或使用桌面小组件时，本应用会向您请求地理位置（定位）权限。我们在不同平台及组件中的处理逻辑如下：

  • Android 设备：仅限在主应用运行期间处理位置信息。位置数据（经纬度）仅在必要刷新时，通过安全的 HTTPS 加密网络连接瞬时发送至第三方天气服务商（Open-Meteo，官方网站: open-meteo.com）的 API 获取当前天气，我们不进行任何后台持续定位或位置数据存储。
  • iOS 设备与桌面小组件（Widget）：
    • 主应用与小组件通信：当您在 iOS 系统中启用本应用时，经纬度信息会以高度安全的本地 App Group 共享机制（Suite: group.xyz.tinglo.Mao4App）在设备本地的 UserDefaults 中同步，以便桌面小组件（MaoWidget）能实时读取。该数据完全留存在设备本地。
    • 小组件后台刷新：iOS 桌面小组件会在系统调度的后台刷新期间，读取此本地经纬度，并直接在小组件进程中向 Open-Meteo API 发起加密 HTTPS 网络请求以更新桌面小组件的温度和空气质量。

    • 🚨 特别说明与承诺：“桌面小组件（Widget）及小组件后台天气同步”功能仅在 iOS 设备上提供与支持，Android 设备不包含小组件功能。我们绝对不在任何外部云端服务器上收集、记录、储存或回传您的位置轨迹、历史定位信息。您的经纬度数据绝不与您的任何设备标识符（如 IDFA/IMEI）或个人身份进行绑定。

3. 其他设备权限的使用

为了给您提供高品质的使用体验，本应用还可能会在必要时请求并使用以下硬件权限或通知通道：

  • 通知权限（Local Notifications）：用于实现每日上午的“早安推送”提醒。该通知的触发、渲染与管理完全在您设备本地由系统原生通知引擎调度执行，整个流程完全不需要网络连接，亦不向外发送任何数据。
  • 触觉反馈权限（Haptics）：用于在您长按、点击或切换主题卡片时提供震动回馈，以实现极佳的原生交互手感。该权限仅限在硬件层交互，不涉及任何数据的读取和存留。

4. 第三方 SDK 与数据安全

本应用没有集成任何第三方商业广告 SDK、用户追踪分析系统（例如 Google Analytics、Firebase、Flurry）或者社交平台一键分享组件。没有任何第三方机构能够以自动化方式透过本应用获取或收集您的任何偏好或个人数据。

5. OTA 自动更新检测

本应用内置了轻量级的 OTA 版本检测机制。当检测更新时，应用会访问云端的静态配置文件（经过 AES 对称加密的 JSON 包）。整个过程仅对比客户端的版本号，不收集、不追踪您的设备硬件特征。若设备处于离线状态，则自动忽略更新，不干扰您的日常使用。

6. 儿童隐私保护说明

我们非常重视对未成年人隐私的保护。由于本应用不建立用户账户系统，我们亦不主动向任何人收集任何个人数据。如果家长有合理理由怀疑我们在无意中获得了未成年人的隐私数据，请通过以下方式联系我们，我们将立即协助您核实并清除本地配置。

7. 政策修订

在添加新功能或遵循相关法律政策时，我们可能会不时对本隐私政策进行小幅更新。任何修订一经本页面公布即时生效，建议您定期关注。对于原生系统权限的重大变更，我们会在应用内显著提示并征得您的明确同意。
